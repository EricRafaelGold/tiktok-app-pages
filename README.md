# WhitePhoenix Studio

WhitePhoenix Studio is a video scheduling and automation platform for TikTok content creators. Connect your TikTok account via OAuth and automatically post videos on a daily schedule — no manual effort required.

## Features

- Daily video scheduling at custom times
- Auto-posting via TikTok's official Content Posting API
- Caption and hashtag management per video
- Secure OAuth authentication — credentials never stored
- Queue management for your full video library
