# WhitePhoenix Studio

WhitePhoenix Studio is a video scheduling and automation platform for content creators. Connect your TikTok account and automatically post videos on a daily schedule.

## Features

- Daily video scheduling
- Auto-posting via TikTok Content Posting API
- Caption and hashtag management
- Secure OAuth authentication
